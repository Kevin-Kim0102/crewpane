      使用定位
      本项目是 Subagent 工作台，仅用于执行主 Agent 委派的任务，不建议直接作为主 Agent 独立完成开发。建议由 Codex 等主 Agent 拆解需求、派发任务、协调编码与测试，并审核和最终验收。面板中的直接消息用于补充指令和排查问题。
      
   
      
    
      第一次使用，怎么开始对话？
      在「设置 → CLI 连接」连接 Claude Code 或 Kiro CLI，并保存默认模型。回到对话页，点击项目旁的「＋」，在输入框下方选择已连接的 CLI，再发送消息。
      
    
      为什么 Codex 无法派发任务给角色？
      在「设置 → Subagent 角色」确认角色已启用，并选择可用的 CLI。模型可以单独指定，也可以跟随该 CLI 已保存的默认模型。
      
    
      面板打不开，怎么重新启动？
      告诉 Codex「启动 Coder-Agents，打开面板」，或在项目目录运行 python3 -m coder_agents start，再打开命令返回的地址。
